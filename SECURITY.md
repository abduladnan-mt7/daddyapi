# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through GitHub instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Useful details: the affected package (`@daddyapi/cli`, `@daddyapi/core` or `@daddyapi/spec`), the version or commit, steps to reproduce, and the impact. You'll get a reply as soon as possible, and fixes are released before details are published.

## Scope

Examples of what's in scope: the HTTP API served by `daddyapi dev`, spec loading and hook execution, the cache, and `robots.txt` handling. Problems with third-party websites that a spec targets are out of scope.
